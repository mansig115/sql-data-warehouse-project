# sql-data-warehouse-project
**Overview**

This project demonstrates the design and implementation of a modern SQL-based Data Warehouse and Analytics solution. The objective was to build a scalable data warehouse by integrating ERP and CRM datasets, transforming raw data into business-ready insights for reporting and decision-making.

The project follows industry-standard Data Engineering and Analytics practices including ETL workflows, Medallion Architecture, Star Schema modeling, and SQL-based analytical reporting.

**Project Objectives**
>> Data Engineering
>> Build a modern SQL Data Warehouse using SQL Server
>> Integrate ERP and CRM source systems from CSV files
>> Perform data cleansing, transformation, and standardization
>> Design a scalable analytical data model
>> Implement ETL workflows for automated data processing
>> Create documentation for data lineage and data models
>> Data Analytics

Develop SQL-based analytics and reporting to generate insights into:

>> Customer Behavior
>> Product Performance
>> Sales Trends
>> Business KPIs and Revenue Metrics
>> Architecture

The project follows the Medallion Architecture approach:

Bronze Layer → Raw source data ingestion
Silver Layer → Cleansed and transformed data
Gold Layer → Business-ready analytical models
Data Modeling

Implemented a Star Schema data model including:

Fact Tables
Dimension Tables
Surrogate Keys
Business-friendly reporting views
